## Long description (itch body — HTML allowed)

```html
<p><strong>Strategos</strong> is a tactical command simulation: topographic maps, NATO APP-6D symbology, and multi-echelon orders from a squad tutorial up through campaign fights.</p>

<p><strong>How to play</strong></p>
<ol>
  <li>Download the Windows build, unzip, run <code>Strategos.exe</code>.</li>
  <li>From the menu, start <strong>SQUAD TUTORIAL</strong> or <strong>SKIRMISH ONLY</strong>.</li>
  <li><strong>Left-click</strong> a friendly (blue) unit. Arm <strong>MOVE</strong> (<code>M</code>) or <strong>ENGAGE</strong> (<code>E</code>), then click the map / contact — or right-click ground / enemy.</li>
  <li><strong>Space</strong> pauses. <strong>Esc</strong> opens pause (Save / Load / menu). In-game <strong>HELP</strong> and pause <strong>ALPHA LIMITS</strong> list honest gaps.</li>
</ol>

<p><strong>Alpha limits (not bugs)</strong></p>
<ul>
  <li>Little fog of war on the small shipped maps.</li>
  <li>Artillery still fights as direct fire.</li>
  <li>No zone of control, facing, or unit collision.</li>
  <li>Destroyed units stay as wrecks.</li>
  <li>Head-on equal firefights can stall under suppression — flank or dig in.</li>
</ul>
```
